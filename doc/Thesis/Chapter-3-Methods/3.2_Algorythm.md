### Key Methods for Orthology Inference

1. **Tree-Based Methods**  
   - Use tree reconciliation to compare gene trees with reference species trees.  
   - Assign duplication or speciation events to internal nodes.  
   - Accurate due to evolutionary model usage but computationally intensive.  
   - Best suited for small-scale studies (dozens to hundreds of genomes).  

2. **Graph-Based Methods**  
   - Build pairwise distance matrices to approximate genetic distances.  
   - Construct graphs clustering orthologous genes based on similarity.  
   - Scalable for large sequence datasets.  
   - Less accurate compared to tree-based methods.

3. **Hybrid Methods**  
   - Combine scalability of graph-based methods with the accuracy of tree-based methods.  
   - Use graph-based tools for initial ortholog identification, then refine with tree-based validation.

## **Main Components**

### Section 1: Tree Algorithm for Conserved Orthologs

This section focuses on processing phylogenetic trees to identify conserved ortholog relationships:

*Phylogenetic Tree*

    1. **Visual Representation of Evolutionary Relationships**  
    - A diagram that shows how species or genes are related through evolutionary history.  

    2. **Structure of Nodes and Branches**  
    - Internal nodes represent common ancestors, while branches indicate evolutionary divergence.

    3. **Tool for Understanding Speciation and Gene Events**  
    - Used to infer speciation, duplication, and evolutionary events across organisms or genes.

    - **Newick Format**: A compact, parentheses-based notation for representing phylogenetic trees, where branch lengths (e.g., `:0.3`) indicate evolutionary distances between nodes.


1. **Tree Parsing Functions**:

   - `parse_newick_tree`: Reads and parses Newick format tree files
   - `get_species_name`: Extracts species names from gene identifiers
   - `get_all_leafs`: Collects all leaf nodes from a tree clade

2. **Connection Analysis Functions**:

   - `add_connections_as_individual_entries_majority_rule`: Implements a majority-rule algorithm for matching genes between species
   - `add_connections_as_individual_entries`: Alternative method for connecting leaf nodes
   - `calculate`: Computes scores for gene pairs using a scoring matrix
   - `process_tree`: Main tree processing function that traverses the tree and collects ortholog connections
