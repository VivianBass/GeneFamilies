## 1.4. **Methodological Approach**

### _A. Research Design_

- **OrthoFinder**

  - **Purpose**: Identify orthologous gene groups across multiple species to enable cross-species comparison of gene function and expression.
  - **Functionality**:
    - Performs all-vs-all BLAST searches between protein sequences to detect sequence similarities.
    - Normalizes BLAST scores for sequence length and phylogenetic distance to ensure accurate clustering.
    - Utilizes graph-based algorithms to cluster sequences into orthogroups.
    - Infers gene and species trees to map evolutionary relationships.
    - Classifies genes as orthologs, paralogs, or identifies gene duplication events.

- **Algorithm**

  - **Purpose**: Systematic identification and classification of gene groups based on evolutionary relationships.
  - **Key Processes**:
    - Groups genes by sequence similarity and evolutionary history.
    - Detects one-to-one, one-to-many, and many-to-many ortholog relationships across species.
  - **Methods**:
    - Sequence alignment and comparison to assess homology.
    - Graph-based clustering to form orthogroups.
    - Phylogenetic tree reconstruction to map evolutionary relationships.
  - **Workflow**:
    - Input protein sequences → BLAST search → Score normalization → MCL clustering → Tree inference.

- **Lab-Book Workflow**

  - **Purpose**: Generate quantitative expression profiles from raw RNA-seq data for downstream analysis.
  - **Workflow**:
    1. Acquire raw RNA-seq data from DDBJ (PRJDB4481).
    2. Perform quality control and preprocessing steps to ensure data integrity.
    3. Quantify transcript expression using tools like `kallisto`.
    4. Generate expression profiles in the form of TPM (Transcripts Per Million) values for analysis.
  - **Tools**:
    - `gffread`: Converts genome annotations to transcriptome format.
    - `Trimmomatic`: Performs quality filtering and adapter removal on raw reads.
    - `kallisto`: Efficiently quantifies transcript abundance from RNA-seq data.

- **R-Pipeline**

  - **Purpose**: Compare gene expression profiles using distance metrics to evaluate variations across species, tissues, and dietary conditions.
  - **Workflow**:
    - **Input Data**:
      - Gene expression profiles in TPM values and log2-transformed values.
      - Gene family data from OrthoFinder, including ortholog and paralog groups.
    - **Distance Measurements**:
      - Compute distances using metrics like Euclidean distance, cosine angles, and tissue-specific Euclidean distance.
      - Generate statistical summaries, such as mean and median distances, to assess similarity/difference in expression profiles.
    - **Statistical Tests**:
      - Perform t-tests and Wilcoxon rank-sum tests to identify significant differences in gene expression profiles across groups.
      - Apply multiple testing correction using the Benjamini-Hochberg method to control for false discovery rate (FDR).
    - **Visualization**:
      - Generate boxplots to visualize distributions of expression distances, showing individual data points, statistical significance, and summary markers (mean, median, error bars).

- **Pipeline Tests**

  - **Validation**:
    - Perform initial test runs with example datasets to check the functionality of the pipeline.
    - Validate the pipeline against FlyBase reference data to ensure accuracy and reliability.
    - Assess the robustness and reproducibility of results using various datasets.
  - **Quality Control**:
    - Implement data integrity checks to ensure high-quality input data.
    - Verify statistical assumptions, ensuring that tests are applicable and results are valid.
    - Conduct reproducibility tests to confirm that the pipeline yields consistent results across different runs.
